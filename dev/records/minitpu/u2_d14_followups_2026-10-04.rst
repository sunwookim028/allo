.. note::

   ``d14-followups`` (worktree ``scratch/wt-d14f`` from ``origin/u1-pilot`` at
   ``d1e729b4``, which merges ``main`` ``9d48a90f``: core-stateful and
   core-uint-index), its own ``mlir/build`` (configured as ``main``'s).
   Catapult Ultra Synthesis 2024.2/1130128, ``nangate-45nm_beh``, 3.33 ns;
   Verilator 5.052; the ``allo`` env's python. Scratch (Catapult projects,

Two follow-ups to README D-14 that ``u2_unreset_impl_2026-10-02.rst`` left
open: **H5**, ``-RESET_CLEARS_ALL_REGS no`` is design-wide, so a mixed design
(reset and unreset storage in one kernel) was unmeasured; **H4**, a ``UInt``
``Stateful`` was declared signed by every emitter (``ac_int<16, true>``,
``int16_t``).

**Result.** (a) The directive admits a *process* as its object
(``Allowed Object: Solution,Design,Process``, Catapult User and Reference
Manual 2024.2 p. 1371), and the write method ``wr`` is a process from ``go
compile`` on. ``run.tcl`` now sets ``directive set /<top>/<kernel>/wr
-RESET_CLEARS_ALL_REGS no`` after ``go compile``, one line per kernel with
unreset storage, instead of the design-wide line before ``go analyze``. On a
mixed design (unreset ``mem[32]``, reset ``tag[4]``, reset counter ``cnt``, all
in one kernel) the scoped form gives **0 ``if ( rst )`` in the storage, and the
kernel thread's RTL byte-identical to a build with no directive**; the
design-wide form had **also dropped the reset of a thread register**
(``while_v25_sva``, the ``if (we)`` data register) -- the H5 hazard, real. A
Verilator trace with a mid-run reset pulse: ``mem`` keeps 32/32 words, ``tag``
reads 0, ``cnt`` restarts (scoped and design-wide alike; without the directive
``mem`` is reset, with Catapult's active-high ``if ( rst )``). No per-variable
form exists (``Unknown path`` for every spelling), and no refusal of mixing is
needed (D-1): the scoped form honours both declarations. (b) The ``memref.global``
and every ``memref.get_global`` of a ``UInt`` ``Stateful`` now carry the
``unsigned`` attribute, as a local alloc does; the SystemC emitter reads the
sign before it reads the type. ``UInt`` storage is ``ac_int<W, false>`` /
``uint16_t`` on SystemC, Vitis and the Catapult C++ flow. TinyTPU's vhls,
catapult and systemc emissions are **byte-identical** (``6bc774bc...``,
``ade1ab5d...``, ``06d36533...``): it has no ``UInt`` ``Stateful``. Of the 104
MiniTPU unit-variant emissions, 4 change (``vpu_regfile`` ``stateful``
systemc+vhls, ``wire_stateful``, ``comb_unreset``), each by the storage's
declared sign only; every harness verdict is unchanged. Also found and fixed:
the D-11 state save in ``sc_main`` was not guarded by ``__SYNTHESIS__``, so
Catapult's ``go analyze`` **aborted on every ``@ Stateful`` design** since
core-stateful merged (CRD-135, B3).

A. The reset directive, scoped
==============================

**What the tool says.** ``$MGC_HOME/shared/pdfdocs/catapult_useref.pdf`` (via
``pdftotext``), "RESET_CLEARS_ALL_REGS", p. 1371, verbatim::

   This directive informs Catapult on whether all registers in the design are
   required to have a reset pin.
   If use_library, Catapult uses the value listed in the base technology library.
     - For ASIC technologies, this directive is typically set to yes.
     - For FPGA technologies, this directive is typically set to no since the
       registers for most FPGA technologies are reset on startup.
   If yes, all the registers in a design are to be reset.
   If no, only registers that need to be reset for correct simulation results
   are reset. This value should be set to 'yes' to guarantee that the C++ and
   RTL simulations match.
   Allowed Values: use_library, yes, no      Default Values: use_library
   Allowed Object: Solution,Design,Process   Last State Allowed: schedule

and p. 49: "If there is an area difference between reset and non-reset
registers in your technology, this directive can be turned off and
non-essential registers will not be reset." ``RESET_KIND`` (sync/async) and the
``reset_clears_all_regs`` example are the only other mentions; there is no
per-variable form. The shell has no directive help: ``help directive`` and
``help directive RESET_CLEARS_ALL_REGS`` both answer ``help: bad operator
"directive": must be command or message``; ``directive set
-RESET_CLEARS_ALL_REGS -help`` answers ``directive set: not a valid enumeration
value`` (``cat/help.log``).

**The design** (``tests/dataflow/test_systemc_unreset.py::_mixed``, n = 64): one
Wire-only kernel ``rf`` with ``mem: UInt(16)[32] @ Stateful(reset=False)``
(comb read port ``w_qa``), ``tag: UInt(16)[4] @ Stateful = 0`` written by the
thread from the same ``if e:``, ``cnt: UInt(16)[1] @ Stateful = 0``
incremented every iteration; ``src`` and ``sink`` kernels on Wires. Emitted
once (every variant's ``kernel.cpp`` is identical); only ``run.tcl`` differs.
Catapult messages verbatim from ``csyn.log``; "thread" is the module
``rf_0_run``, "wr" the module ``rf_0_wr`` of ``concat_rtl.v``; the Verilator
trace is ``vl/tb.cpp`` (write all 32 words of ``mem`` and ``tag``, read back,
pulse ``rst`` low for 3 cycles with inputs idle, read back again).

top, design_top)`` writes ``directive set /<design_top>/<kernel>/wr`` (or
``/<kernel>/wr`` when the kernel is the ``synth_top``; nothing for a kernel
outside the synthesized design) after ``go compile``; ``hls.py`` passes the

(``unreset_storage_in``). ``docs/source/backends/systemc.rst`` says so. README
D-14's bullet "``-RESET_CLEARS_ALL_REGS no`` for Catapult" stands as written;
the scoped object is an implementation detail of that directive, recorded
here (README is not edited by this record).

B. ``UInt`` ``Stateful`` declared unsigned
==========================================

**Emission sites.** The ``memref.global`` of a ``Stateful`` has a signless
element type; the sign of a ``UInt`` travelled nowhere. ``allo/ir/builder.py``
now sets ``unsigned`` on the global (as on a local alloc) and on every
``memref.get_global`` of it (both creation sites; ``stateful_unsigned`` on the
context holds the symbols, propagated to nested kernels in ``visitor.py``).
Sites that read it, checked one by one:

* ``EmitSystemC.cpp`` ``emitKernelModule``: member declaration (``uint16_t
  mem[32]`` plain, ``sc_signal< ac_int<16, false> > mem[32]`` for comb/unreset
  signal storage), the D-11 ``__allo_state_save/_resume`` casts
  (``(unsigned long long)``, ``(uint16_t)``, ``ac_int<16, false> _v``), the
  reset-action loop and the ``get_global`` placeholder comment. Two of them
  read the type **before** ``fixUnsignedType`` retyped the global (``auto at =
  ... getType()`` first), so the attribute alone still gave ``int16_t``; the
  order is swapped at both.
* ``EmitVivadoHLS.cpp`` ``emitGlobal`` / ``emitGetGlobal`` and
  ``EmitCatapultHLS.cpp`` (the C++ flow): already ``fixUnsignedType(...,
  hasAttr("unsigned"))`` on the global and on the ``get_global``; they only
  needed the attribute. ``static uint16_t __stateful_rf_0_mem_1[32] = {0, ...}``
  now, ``// placeholder for const uint16_t __stateful_rf_0_mem_1``.
* Loads and stores were already right: the result of a ``memref.load`` carries
  its own ``unsigned`` and is materialised as a typed local (``uint16_t v31 =
  __stateful_rf_0_mem_1[v30].read();``). That is why **csim cannot observe the
  old bug**: a value >= 2^15 stored into ``ac_int<16, true>`` and read back
  through ``uint16_t`` is bit-exact (H4's "bits unchanged"). The existing csim
  tests already drive such values (``_trace``: ``wd`` uniform in [0, 2^16);
  ``test_signal_storage_persists_across_csim_calls``: 80-bit values >= 2^79) and
  passed before and after; the discriminating test is the emission test
  ``test_uint_stateful_unsigned`` (IR attribute; systemc, vhls and catapult
  declarations; no ``int16_t __stateful`` anywhere).

**Impact.** ``emit_units.py``: every ``VARIANTS`` entry of every
``examples/minitpu/units`` module at n = 8, systemc and vhls, sha256 of
``hls_code``, base (``d1e729b4``, same bindings) vs branch: 104 lines, **4
differ**, all ``vpu_regfile`` -- ``stateful`` systemc (``int16_t`` ->
``uint16_t`` member and the state-IO casts) and vhls (``static int16_t`` ->
``static uint16_t``), ``wire_stateful`` systemc (as ``stateful``),
``comb_unreset`` systemc (``ac_int<16, true>`` -> ``ac_int<16, false>`` in the
signal storage and in ``_resume``), each also in the ``get_global``
placeholder comment and in the two lines of the ``__SYNTHESIS__`` guard (B3;
a csim-only text change that every ``@ Stateful`` systemc emission gets --
among the unit variants only these three: ``vpu_word_array``'s ``Stateful``
variant is the D-11-refused ``shared``). The ``comb`` variant is unchanged: its
``mem`` is a kernel-local alloc, which carried ``unsigned`` already. ``bf16_add``, ``alu``, ``mul_acc24``, the FIFOs and
word arrays: byte-identical. TinyTPU (``customize(tinytpu_isa)`` +
``schedule``, ``build(target=...)``, the recipe of ``u2_unreset_impl``): vhls
``6bc774bc9d97...``, catapult ``ade1ab5dfd20...``, systemc ``06d365336c30...``
(mode csim, project path replaced) on base and branch -- **identical**.

Findings
========

**A1 (Catapult, hazard confirmed, fixed).** ``-RESET_CLEARS_ALL_REGS no`` on
the design strips the reset of *every* register the C semantics do not need
reset, not only the unreset storage: on the mixed design, the thread's ``if
(we)`` data register (``while_v25_sva``) lost its asynchronous reset (A vs B).
Not observable at the ports here (the register is a don't-care until the
first ``we``), but a silent change to a part of the design that declared
nothing, which D-1 forbids. Scoped to ``/<top>/<kernel>/wr`` the thread's
RTL is byte-identical to the no-directive build (C, E, F, G, H).

**A2 (Catapult, match).** The scoped form honours both declarations in one
kernel: ``mem`` 0 reset flops and 32/32 words kept across a mid-run reset
pulse; ``tag`` and ``cnt`` reset (Verilator, G). No refusal of mixing is
needed.

**A3 (Catapult, info).** The directive's object is a Solution, a Design or a
Process; every per-variable spelling is ``Unknown path`` (P), and the
process must exist (after ``go compile``; before it, ``/rf_0/wr`` is unknown
too). In a hierarchical build the block resolves by module name
(``/top/rf_0/wr``) and by instance name (``/top/u1/wr``) alike; the emitter
uses the module name.

**B1 (frontend, bug, fixed).** A ``UInt`` ``Stateful`` global carried no sign;
every emitter declared it signed (``u2_unreset_impl`` H4). Fixed at the
source (the attribute on the global and its ``get_global``\ s), so the three
HLS emitters agree without a per-emitter patch.

**B2 (SystemC emitter, bug, fixed).** Two declaration sites read the global's
type before applying its sign, so the attribute alone changed nothing there.

**B3 (SystemC emitter, bug, fixed).** The D-11 state save in ``sc_main``
(``t.dut.<k>.__allo_state_save(_f)``) was emitted outside ``#ifndef
__SYNTHESIS__`` while the member is defined only inside it. Catapult parses
``sc_main`` too: ``go analyze`` of **every** ``@ Stateful`` design aborted with
``class has no member __allo_state_save`` (CRD-135) since core-stateful
merged (``9d48a90f``). Found by the first Catapult run of this record; guarded
now, and ``test_mixed_reset_emit`` asserts the guard.

**B4 (SystemC, info).** csim cannot distinguish signed from unsigned storage of
the same width: loads are materialised through typed locals. The sign is a
declaration-level property (and Catapult's); the emission test holds it.
